# Project Summary
The Salon CRM project is a comprehensive digital platform designed to streamline operations for beauty salons. It enables salon owners and staff to manage customer information, appointment scheduling, payments, and promotions effectively. The system automates reminders, stores service history, and generates insightful reports, enhancing both customer experience and business efficiency. Future expansions may include inventory management and payroll features.

# Project Module Description
## Core Modules
- **Customer Management**: Create and manage customer profiles and service history.
- **Appointment Scheduling**: Schedule appointments with availability checks and automated reminders.
- **Staff Management**: Manage user roles (SuperAdmin, Owner, Staff) and permissions.
- **Payment Management**: Record payments, generate invoices, and track transaction history.
- **Promotions Management**: Create and send promotional messages via SMS and email.
- **Reporting**: Generate job, financial, and staff performance reports.

# File Description Inventory
- **src/config/**: Contains configuration files for database and server settings.
- **src/services/**: Implements business logic for user authentication, customer management, appointment handling, payments, promotions, and reporting.
- **src/models/**: Defines data access layers for users, customers, appointments, services, payments, and promotions.
- **src/middleware/**: Contains custom middleware for authentication.
- **src/graphql/**: Holds GraphQL schema definitions and resolvers for various functionalities.
- **prisma/**: Contains the database schema and seeding scripts for initial data population.
- **README.md**: Project documentation and usage instructions.

# Technology Stack
- **Backend**: Node.js with Express.js
- **API**: GraphQL using Apollo Server
- **Database**: PostgreSQL managed with Prisma ORM
- **Containerization**: Docker for deployment
- **Authentication**: API Key and JWT tokens
- **Validation**: Joi for input validation
- **External Services**: Twilio (SMS), Nodemailer (Email)

# Usage
### Installation
1. Clone the repository and navigate to the project directory.
2. Copy the `.env.example` to `.env` and update the configuration.
3. **Using Docker (Recommended)**:
   - Start all services with `docker-compose up -d`.
   - Generate the Prisma client with `docker-compose exec app npx prisma generate`.
   - Run database migrations with `docker-compose exec app npx prisma db push`.
   - Seed the database with `docker-compose exec app npm run db:seed`.

4. **Local Development**:
   - Install dependencies with `npm install`.
   - Generate the Prisma client with `npx prisma generate`.
   - Run database migrations with `npx prisma db push`.
   - Seed the database with `npm run db:seed`.
   - Start the development server with `npm run dev`.

### Accessing the API
- Use GraphQL Playground for testing API queries.
- Health check endpoint available for monitoring.
